# «Дед внутри» — роадмап до релиза

_Статус: 2026-10-26 — этап 0, готовим окружение._

## Этап 0 — Окружение (сейчас)
- [ ] Unity Hub + Unity 6 LTS, модуль Windows Build Support (IL2CPP) — **только после подтверждения пользователя** (правило: установки — всегда с разрешения)
- [ ] Создать проект `ded-inside` (шаблон 3D URP), git-репозиторий, перенести GDD/ROADMAP внутрь проекта (`ded-inside/docs/`)

## Этап 1 — МВП, серый бокс (4–6 недель)
- [ ] Гроб: физика ~120 кг, 4 ручки, крен >50°/70°, крышка/дно, плавание, режим санок
- [ ] Дед: рэгдолл 80 кг, урон от ударов/падений/воды, дед-метр, стильные спасения, перенос на руках/плече
- [ ] Персонаж: движение, физический захват, рэгдолл при ударе, локтевой пуш
- [ ] Уровень «Деревня-1»: 4 сегмента, чекпоинты, церемония
- [ ] Оценка: формула оплаты, звёзды, экран «Хроника смены» с автоскриншотами
- [ ] Онлайн 1–2 игрока: хост-лобби Steam, proximity-войс
- **Критерий готовности:** даём другу — смеётся и просит ещё уровень.

## Этап 2 — Регион «Деревня» (мес. 2–3)
5 заказов + спецзаказ, смотритель, гуси/вороны/корова, магазин и снаряжение, звук.

## Этап 3 — Вертикальный срез качества (мес. 3–4)
Финальный арт-стиль на одном уровне: палитра, освещение, постпроцессинг, UI-дизайн-система. Ревью с пользователем по скриншотам.

## Этап 4 — «Город» + демо (мес. 5–6)
Регион «Город» (6 заказов), страница Steam, демо на Next Fest, Remote Play Together.

## Этап 5 — «Горы» + «Море» (мес. 7–10)
Контент, полировка, локализация RU/EN, оптимизация.

## Этап 6 — Релиз 1.0
4 региона, цена ~$10. «Космос» — бесплатное крупное обновление через 3–4 месяца после релиза.

---
Правила проекта: новый регион = максимум 2 новые механики; сегмент уровня ≤ 60 сек; установки ПО — только с явного подтверждения пользователя.
