# ДЕД ВНУТРИ (Dead Inside)

Кооп-комедия на физике, 1–4 игрока: работники похоронного бюро несут гроб с
рэгдолл-дедушкой (не пристёгнут!) к месту захоронения — через пригорки, пруды,
грядки, овраги и коров. Дед выпадает — ловите. За спасения дают очки стиля.

**Статус:** этап 2 роадмапа — 3 заказа «Деревни», прогрессия, лавка, сеть.

## Как играть
1. Unity 6.6 (6000.6.7f1) + Unity Hub → открыть проект → Play.
2. Меню: **СМЕНА** — выбор заказа (открываются по звёздам), **ЛАВКА** — снаряжение,
   внизу — чувствительность мыши и сетевые кнопки.

## Заказы «Деревни»
| Заказ | Маршрут | Фишки |
|---|---|---|
| 1 · Пригорок | дом → пригорок → пруд по мостку → кладбище | санки на спуске, гуси |
| 2 · Огород | дом → грядки → брод через ручей → кладбище | гроб через борты, вода |
| 3 · Сеновал | дом → крутой подъём → мост через овраг → корова → спуск | корова лежит на дороге |

В каждом: церемония захоронения (E), завещание деда (конверт Буканову),
трость (+30% чаевых), хроника смены (автоскриншоты на экране оценки).

## Управление
| Клавиша | Действие |
|---|---|
| WASD | идти (относительно камеры) |
| Space | прыжок (с койот-таймом) |
| ЛКМ (держать) | схватить; мышь ↑↓ — поднять/опустить объект |
| Esc | пауза (продолжить / в меню / выход) |
| E | засыпать (на церемонии) |
| R | повторить заказ (после оценки) |

## Сеть (серый бокс)
Меню → «ХОСТИТЬ СМЕНУ» на одном ПК, «ПОДКЛЮЧИТЬСЯ К ДРУГУ» + IP на другом
(одна сеть). Хост-авторитарная физика: гроб/дед/гуси симулирует хост,
захваты клиентов передаются на сервер. Proximity-войс — на этапе 3.
