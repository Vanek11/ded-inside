# ДЕД ВНУТРИ (Dead Inside)

Кооп-комедия на физике, 1–4 игрока: работники похоронного бюро несут гроб с
рэгдолл-дедушкой (не пристёгнут!) к месту захоронения — через лестницы, пруды,
склоны и гусей. Дед выпадает — ловите. За спасения дают очки стиля.

**Статус:** МВП, серый бокс (этап 1 роадмапа).

## Документы

## Как открыть проект
1. Unity 6.6 (6000.6.7f1) + Unity Hub.
2. В Hub: Add → выбрать папку проекта → открыть.
3. Дождаться импорта. Меню **DeadInside → Построить и сохранить сцену «Деревня-1»**.
4. Жми Play.

## Управление (серый бокс)
| Клавиша | Действие |
|---|---|
| WASD | идти (относительно камеры) |
| Space | прыжок |
| ЛКМ (держать) | схватить/нести (гроб, дед, крышку) |
| Esc | показать курсор |
| R (после сдачи заказа) | заново |

## Цель демо-уровня «Деревня-1»
Донести гроб с дедом из дома до могилы на кладбище: крыльцо → дорога →
пригорок (на спуске гроб едет санками) → пруд по мостку (гуси!) → подъём →
кладбище. Поставь гроб в зону могилы и подожди секунду.
